# Pipa release notes template

Use this template for the GitHub release. Replace the prompts with evidence for
the release; omit sections that do not apply. Do not imply a demo shows a new
feature unless it actually does.

## Highlights

- Describe the user-visible changes and link to the relevant PRs.

## Demo

[Watch the Pipa setup video](https://www.youtube.com/watch?v=rlTMdkPWPcA).
Link to a feature-specific demo here if one exists.

## Install and upgrade

Give the exact version and channel, upgrade steps, and any compatibility or
rollback guidance.

## Verification and limitations

Link to release evidence. State which checks passed, what was not tested, and
any known limitations without implying broader qualification.
